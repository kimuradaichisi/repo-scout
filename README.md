# RepoScout

RepoScout is a local repository investigation runner that executes evidence-collection
queries generated by commercial coding agents and returns compact, source-grounded evidence.

## Goal

Reduce repository-discovery work performed by commercial coding agents such as Claude Code.

RepoScout does **not** replace the commercial model's reasoning. It offloads broad, repetitive
repository investigation to local deterministic tools and, when necessary, a local Ornith worker.

## MVP Scope

Included:

- `rg` text search
- bounded file reads
- `git log`
- single-query Ornith worker
- multi-query investigation plans
- one fresh Ornith invocation per query
- machine-generated Evidence Pack

Not included yet:

- MCP server
- LSP
- AST graph
- implementation delegation
- long-term agent memory
- RAG/vector database

## Architecture

```text
Claude Code
    |
    | Investigation Plan
    v
RepoScout
    |
    +-- deterministic executors
    |     +-- ripgrep
    |     +-- file read
    |     +-- git
    |
    +-- Ornith worker
          |
          +-- OpenCode CLI
    |
    v
Evidence Pack
    |
    v
Claude Code
```

RepoScout treats local model output as **navigation evidence**, not as an authoritative semantic
conclusion.

## Requirements

- Python 3.12+
- `uv`
- `rg`
- `git`
- OpenCode available on `PATH` for Ornith queries

```bash
uv sync --extra dev
```

## Single deterministic query

```bash
uv run reposcout query \
  --root ../target-repo \
  --id Q1 \
  --tool rg \
  --pattern ExecuteContract \
  --path tools \
  --path tests
```

## Single Ornith query

```bash
uv run reposcout query \
  --root ../target-repo \
  --id Q1 \
  --instruction "ExecuteContract の参照箇所を検索し、ファイル名・行番号・該当行だけ返せ"
```

The default Ornith command is configured in `src/reposcout/ornith/client.py`.
Adjust it to match your OpenCode agent/model setup.

## Investigation Plan

Example:

```yaml
goal: ExecuteContract 変更の影響範囲を調査する

queries:
  - id: Q1
    tool: rg
    pattern: ExecuteContract
    paths:
      - tools
      - tests

  - id: Q2
    tool: read
    file: tools/dev_agent/application/execute_contract.py
    start_line: 1
    end_line: 220

  - id: Q3
    instruction: >
      ExecuteContract を利用するテストを調査し、
      ファイル名・行番号・該当行だけ返せ。
```

Run:

```bash
uv run reposcout investigate \
  --root ../target-repo \
  examples/investigation.yaml
```

Output:

```text
.reposcout/
└── runs/
    └── <run-id>/
        ├── plan.yaml
        ├── Q1.json
        ├── Q2.json
        ├── Q3.json
        └── evidence.md
```

## Repository Skeleton

```bash
uv run reposcout skeleton --root ../target-repo
```

Prints tracked paths under `src` and `tests/unit` -- the deterministic source of
truth a caller's `target_hints` (kind `path`) can be checked against.

## Evidence Pack (Pack First)

Merges and deduplicates requested source ranges into one deterministic Pack,
instead of the caller reading the same or overlapping ranges multiple times.
See [`docs/pack_first_policy.md`](docs/pack_first_policy.md) for when a Strong
Model should call this before individual reads.

```yaml
# request.yaml
ranges:
  - path: src/reposcout/evidence.py
    start_line: 1
    end_line: 20
  - path: src/reposcout/evidence.py
    start_line: 15
    end_line: 30
```

```bash
uv run reposcout pack request.yaml --root ../target-repo
```

Outputs one merged, hashed `PackedSource` per non-overlapping range, plus
`PackMetrics` (`requested_ranges`, `packed_ranges`, `requested_source_bytes`,
`packed_source_bytes`, `duplicate_or_overlap_bytes_eliminated`, `unique_paths`,
`pack_chars`) -- all computed deterministically, with no LLM call involved.

## Core rule

**Planning may be batched. Ornith execution is one query per fresh invocation.**

This intentionally prevents conversation-history contamination between repository investigations.
